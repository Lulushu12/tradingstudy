2. The honest edge estimate
========================================================================================
studied data : +0.1426R  (n=3391, bootstrap SE ~0.053)
holdout      : -0.6135R  (n=52,   SE ~0.123)
inverse-variance posterior: +0.0238R  SE 0.0488  95% CI [-0.0717, +0.1194]

Caveat that matters more than the arithmetic: this blend assumes one
stationary edge. The per-year table (+0.23, +0.22, +0.01, +0.08, +0.09,
+0.37) says the edge is regime-conditional, so the forward value depends
on the future regime mix, which is not estimable from this data.
