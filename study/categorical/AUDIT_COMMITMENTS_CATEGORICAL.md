# AUDIT COMMITMENTS - Categorical Fade v1, Phase 1

Written BEFORE Phase 1 was executed. Immutable once results exist. If I am asked to change any
threshold in this file after seeing results, the correct response is to refuse.

**Contamination disclosure up front:** these thresholds were written after Gate 0 results existed.
I know the pooled per-trade figure is around +0.10 R and that the sign held in 6 of 6 years. So
this is an informed test, not a blind one. It can still falsify the system on dimensions Gate 0
never measured: causal thresholding, compounding, sequencing, drawdown, losing streaks, and
pessimistic both-touched resolution. It cannot confirm anything. Only a quarantined holdout can
do that, and none exists yet.

## 1. Cost and slippage assumptions (pre-committed)

| Component | Base case | Justification |
|---|---|---|
| Commission | 0.04% per side, 0.08% round trip | repo standing assumption, UNVERIFIED |
| Slippage | 0.02% per fill | market orders on a liquid perp, 4H bars, no size constraint modelled |
| All-in | 0.12% round trip | |

Funding is not modelled. This is a known omission, not an assumption.

## 2. Walk-forward scheme

No parameters are fitted in Phase 1, so there is nothing to refit. "Walk-forward" here means the
threshold is causal and the reporting is sliced out of sample by construction:

- The ER percentile threshold at bar t uses only ER history before t (expanding window, 2,000-bar
  warmup). Every signal is therefore generated by information available at the time.
- Results are reported per calendar year and pooled.
- Additionally reported per regime: bull / bear by the sign of the trailing 200-bar close change,
  and high-vol / low-vol by whether ATR14/close sits above or below its own expanding median.

## 3. Kill thresholds (pre-committed, applied verbatim)

The system is DEAD if any of the following holds on studied data:

| # | Metric | Kill condition |
|---|---|---|
| K1 | Pooled net expectancy per trade after 0.12% round-trip costs | `<= 0` |
| K2 | Trade count | `< 300` (too few for any inference; not a pass, a "cannot say") |
| K3 | Pooled profit factor | `< 1.10` |
| K4 | Years with positive net expectancy | `< 4 of 6` |
| K5 | Cost headroom: multiple of base cost at which pooled expectancy crosses zero | `< 1.5x` |
| K6 | Max drawdown on 1% risk sizing | `> 35%` |

K5 is the one that matters most. An edge that dies at 1.2x assumed costs is an edge that dies the
first time the fee schedule is wrong or a fill is bad.

## 4. What "survives" means

Surviving every threshold above means **not yet falsified on data that was already studied**. It
is not evidence the system works. The rules were selected by looking at this exact history during
Gate 0, so a pass is the expected outcome of a well-executed curve fit and carries almost no
information. The only statement Phase 1 can support is the negative one: if it fails here, it is
dead, and no amount of tuning on this data resurrects it.

## 5. Pre-committed response to a partial failure

If some kill thresholds pass and others fail, the system is DEAD. There is no partial credit and
no "close enough." Specifically:

- If K5 fails but K1 passes, the system is dead. A positive expectancy with no cost headroom is a
  fee-schedule bet, not an edge.
- If K4 fails but the pooled numbers pass, the system is dead. A pooled edge assembled from a
  minority of years is a regime bet wearing a system costume.
- If the causal threshold degrades the result below any line above, that is the honest number and
  the pooled Gate 0 figure is discarded, not averaged in.

## 6. What is explicitly NOT permitted in Phase 1

- No parameter changes. ER lookback stays 20. Donchian stays 20. ATR buffer stays 1.0. Percentile
  stays 10. Max hold stays 200.
- No filter additions.
- No re-running with a different threshold after seeing a failure.
- No substituting the direction template for the fade template if the fade fails.
- No moving to a different asset to find a pass.
