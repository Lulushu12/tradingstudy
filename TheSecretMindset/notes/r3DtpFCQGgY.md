## Strategy 1: 9-Point Trend Rating System

### Indicators and settings

**Pillar 1: Structure (3 points max)**
- Stair-step pattern: Yes = 1 point, No = 0 [00:30-01:30]
- Danger line (midpoint between swing high/low): pullbacks above/below = 0, pullbacks respecting line = 1 point [02:00-02:30]
- Pattern breakout: if lower high (uptrend) or higher low (downtrend) forms = 0, pattern intact = 1 point [03:00-03:30]

**Pillar 2: Momentum (3 points max)**
- Candle body size: large/thick bodies in trend direction = 1 point, shrinking bodies = 0 [04:30-05:00]
- Rhythm: even/consistent pace from one high to next = 1 point, slowing dramatically = 0 [06:00-06:30]
- Volume: volume increases on trend direction candles = 1 point, volume on wrong side = 0 [06:30-07:30]

**Pillar 3: Exhaustion (3 points max)**
- Climax candle: absence of peak = 1 point, single massive high-volume candle = 0 [08:00-08:30]
- Divergence: no divergence (price vs. RSI/MACD) = 1 point, significant divergence = 0 [08:30-10:00]
- Character change: trend feels consistent/predictable = 1 point, trend feels restless/hesitant = 0 [10:00-10:30]

### Context / bias filter
- Only trade if total score ≥ 7 points (strong trend) [11:00]
- Wait if score 4-6 (weak trend) [11:30]
- Stay away if score 0-3 (fading trend) [11:30]
- Can be applied on any timeframe [11:30]
